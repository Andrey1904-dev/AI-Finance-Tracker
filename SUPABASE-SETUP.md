# Подключение Supabase

1. Открой Supabase Dashboard своего проекта.
2. Перейди в **SQL Editor → New query**.
3. Скопируй весь файл `supabase-schema.sql`, вставь и нажми **Run**.
4. Открой **Authentication → Providers** и включи **Anonymous sign-ins**.
5. Залей содержимое этой папки в GitHub Pages.

После этого приложение будет:
- автоматически создавать анонимную сессию;
- загружать операции из Supabase;
- сохранять новые операции в Supabase;
- продолжать работать локально, если база временно недоступна.

Ключ `sb_publishable_...` предназначен для клиентского приложения. Никогда не публикуй `service_role`/secret key.
