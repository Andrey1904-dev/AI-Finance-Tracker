# AI Finance Tracker

> A modern AI-powered personal finance management platform designed to make expense tracking simple, intelligent, and visually engaging.

AI Finance Tracker is a premium personal finance application that combines a beautiful fintech-style dashboard with intelligent transaction processing through Telegram.

Users can record expenses and income manually or send natural-language messages to a Telegram bot, such as:

> Bought groceries for 5,000 rubles

The system identifies the transaction type, amount, category, date, and description, then displays the operation in the finance dashboard.

## 🧠 Example

A user sends a Telegram message:

```text
Bought groceries for 5,000 rubles
```

The application interprets it as:

```text
Type: Expense
Category: Groceries
Amount: 5,000 ₽
Date: Today
Description: Grocery purchase
```

The transaction can then be confirmed and added to the dashboard.
